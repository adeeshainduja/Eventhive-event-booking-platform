# EventHive Backend API

EventHive is an event booking and venue management backend system built with Node.js, Express.js, MySQL, Sequelize, and JWT authentication.

## Technologies Used

- Node.js
- Express.js
- MySQL
- Sequelize ORM
- JWT Authentication
- bcryptjs
- CORS
- dotenv

## Main Features

- User registration and login
- JWT-based authentication
- Role-based access control
- Venue creation and admin approval
- Event creation and admin approval
- Ticket booking system
- Payment record management
- Review and rating system
- Admin dashboard statistics

## User Roles

- user
- organizer
- venue_owner
- payment_manager
- admin
